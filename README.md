## 2. Technical Architecture

The portfolio website is built on a modern, component-based architecture, leveraging the power of React and Vite for a fast and efficient development experience.

### 2.1. Tech Stack

The following technologies were used to build this project:

| Category          | Technology        |
| ----------------- | ----------------- |
| **Frontend**      | React, Vite, TypeScript, Tailwind CSS, Shadcn/ui |
| **Linting**       | ESLint            |
| **Package Manager** | npm               |

### 2.2. Project Structure

The project is organized into a modular structure, with a clear separation of concerns:

```
/src
|-- /assets
|-- /components
|   |-- /portfolio
|   |-- /ui
|-- /hooks
|-- /lib
|-- /pages
|-- App.tsx
|-- main.tsx
```

- **`assets`**: Contains static assets such as images and icons.
- **`components/portfolio`**: Contains the main components that make up the portfolio sections (e.g., `HeroSection`, `AboutSection`).
- **`components/ui`**: Contains reusable UI components from Shadcn/ui.
- **`hooks`**: Contains custom React hooks for shared logic.
- **`lib`**: Contains utility functions.
- **`pages`**: Contains the main pages of the application.

## 4. Getting Started

To get a local copy up and running, follow these simple steps.

### 4.1. Prerequisites

Make sure you have Node.js and npm installed on your machine.

- **npm**
  ```sh
  npm install npm@latest -g
  ```

### 4.2. Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/sattusaipraneeth/SaipraneethSattu-Portfolio.git
   ```
2. **Navigate to the project directory:**
   ```sh
   cd SaipraneethSattu-Portfolio
   ```
3. **Install NPM packages:**
   ```sh
   npm install
   ```
4. **Start the development server:**
   ```sh
   npm run dev
   ```
   The application will be available at `http://localhost:8080`.
